# Guía de bienvenida de Jarvis

Cuando el usuario ejecuta `/new` o `/reset`, este hook responde con un mensaje
largo que lista todas las herramientas disponibles, sus usos y los comandos
del bot, para que cada sesión nueva empiece con el catálogo completo a la vista.
