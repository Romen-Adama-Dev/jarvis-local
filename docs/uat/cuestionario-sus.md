# Cuestionario SUS (System Usability Scale)

Se rellena al terminar la ronda **con Jarvis**. Cada afirmación de 1 (totalmente en
desacuerdo) a 5 (totalmente de acuerdo). Versión en español de la escala de Brooke (1996).

| # | Afirmación | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | Creo que me gustaría usar este sistema con frecuencia. | | | | | |
| 2 | Encontré el sistema innecesariamente complejo. | | | | | |
| 3 | Pensé que el sistema era fácil de usar. | | | | | |
| 4 | Creo que necesitaría ayuda de una persona técnica para poder usar este sistema. | | | | | |
| 5 | Encontré que las distintas funciones del sistema estaban bien integradas. | | | | | |
| 6 | Pensé que había demasiadas incoherencias en el sistema. | | | | | |
| 7 | Imagino que la mayoría de la gente aprendería a usar este sistema muy rápido. | | | | | |
| 8 | Encontré el sistema muy engorroso de usar. | | | | | |
| 9 | Me sentí muy seguro/a usando el sistema. | | | | | |
| 10 | Necesité aprender muchas cosas antes de poder empezar a usar el sistema. | | | | | |

**Puntuación**: en las impares, (respuesta − 1); en las pares, (5 − respuesta). Se suman
y se multiplica por 2,5: resultado de 0 a 100. 68 es la media de referencia.

**Preguntas abiertas** (entrevista de 5 minutos):

1. ¿Qué tarea te ha ahorrado más trabajo? ¿Y cuál menos?
2. ¿Hubo algo que Jarvis hiciera mal o que no te fiaras de lo que decía?
3. ¿Lo usarías en tu trabajo? ¿Qué le falta para eso?
